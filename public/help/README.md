# Slike za ekran pomoći

Ovdje idu slike ekrana koje se prikazuju u Pomoći. Dok slike nema, prikazuje se
mjesto za nju.

Ime datoteke je `<slug-naslova>-<mobile|desktop>.png`, gdje je slug naslov iz
`<x-help-preview title="...">` preveden u mala slova sa crticama.
